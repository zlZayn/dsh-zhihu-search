## 什么时候必须重截

判据是「卡片渲染出来的东西有没有变」，不是「改了哪个文件」。
与 [release-guard.mjs](../scripts/release-guard.mjs) 同一种分工：它只判路径，行为等价的改动交给人回答。

必须重截：

- `src/client/locales.ts` 两份字典的**文案值**（中英任一）
- `src/client/index.tsx` 的 **JSX 结构**：字段增删、顺序、按钮、状态行
- `src/client/index.tsx` 的**样式对象**：字号、行高、间距、令牌、布局
- 卡片**可见状态**的语义：未保存标记、已配置 / 未配置徽标、已覆盖 + 重置、只读遮蔽行、失败诊断

不必重截：

- 类型与注释（只活在编译期）
- 行为等价的内部重构：抽常量、改名、等价重写
- `README` / `AGENTS` / 测试 / 构建配置
- `inject`、注册 key、`dsh.client.*`：它们坏了是「卡片装不上」，不是「图不准」

拿不准时按「必须重截」办：图的成本低于一张与界面不符的图。

## 完成定义

- 改渲染面的改动，**要么同批带重截图，要么在 commit body 里写明为什么不重截**。
- 图与文案分成两个提交，会留下「文案已改、README 里的图还是旧的」的窗口。

## 怎么截

截图会改**全局设置**（语言等），所以第 0 步是问，不是动手。

0. **先问再动**，问的时候说清三件事，再等维护者确认：
   - 要占用浏览器几分钟；
   - 会临时切界面语言，结束切回；
   - **截图期间请别改语言 / 主题 / 模型等全局设置** —— 它们直接进画面。
1. **用自己的标签页，不动维护者的标签页**：agent 端点新开一个页面打开 GUI 即可（实测与原标签页并存、登录态照常），结束时关掉它。
2. **开一个新会话**，再按 [README.md](README.md) 的「风格基准」把画面摆到位；摆好后**不再动任何别的东西**。
3. 打开「设置 → 插件 → 插件配置」，**展开**知乎搜索卡片，滚到卡片完整可见（底部「放弃 / 保存」必须在图内）。
4. **开关状态照现状拍**：拨它会带出「未保存」标记，真保存又改了维护者的真实配置。
5. 先拍中文，再临时把界面语言切成 English 拍英文，然后**把语言切回原状**。
6. **交还**：关掉设置面板 → 关掉自己的标签页 → 把当前会话切回维护者原来那个（会话选择会被记住，下次开页面落在它上面）→ 告诉他可以用了。

## 已知约束

- 整屏尺寸拿不到：agent 端点进不了浏览器全屏 —— 浏览器域 CDP 被 TabbitDance 拒、`--foreground` 不是合法参数、Fullscreen API 返回 `not granted`。基准因此不写死像素（见 [README.md](README.md)）。

## 验收

- 卡片完整：标题、副标题、三个字段行、状态行、说明行、底部按钮
- 说明文案与当前 `locales.ts` **逐字一致**
- 尺寸与风格符合 [README.md](README.md) 的「风格基准」
