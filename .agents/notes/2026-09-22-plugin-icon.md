# 插件图标：把 `assets/logo.svg` 里那只**蓝色方标**烘进 36×36 的 `icon.svg`

**一轮之内给包根补上 `icon.svg` 并声明它，这是它的决策记录。**
几何与配色一律是本机算出来的（解析 path 数据 + WCAG 相对亮度），不是目测。

## 问题

宿主 0.1.7 支持插件自带图标（顶层 `"icon": "./icon.svg"`），官方两个实验包都有；
本插件此前的决策是[**不加**](2026-09-22-plugin-display-metadata.md)（仓库没有可用资产，硬造等于替维护者定视觉方向）。
本轮用户拍板**两仓都加**，并指定 zhihu 这一侧的素材与形态：

> 「`assets/logo.svg` 放在中央，**不是白底**因为要兼容亮暗模式」

## 宿主的硬约束（`packages/boot/app-boot/src/package-meta.ts` 的 `iconOf`，逐条核过）

相对路径；扩展名限 `.svg/.png/.jpg/.jpeg/.webp`；**realpath 后必须留在清单目录内**；普通文件；**≤ 256 KiB**；
返回 **base64 data URL → 按图片渲染**（所以 `currentColor`、外链图片、外部 CSS 与字体**一律不起作用**，必须自包含）。

## 素材勘查：`assets/logo.svg` 是三块，不是一块

它是 `viewBox="0 0 523 346"` 的横版**字标**（15.8 KB），三个 path 各是一种色，外接框（锚点法）实测：

| path | fill | 外接框（源坐标） | 是什么 |
|---|---|---|---|
| #1 | `#1F5B95` 深蓝 | x 48.8–476.5，y 295.9–333.8 | 底部一行小字（高 37.9） |
| #2 | `#0084FF` 知乎蓝 | x 257.2–518.3，y 33.3–294.4（**261.1 × 261.1**） | **那只圆角方标**（知乎图形本身，正方形） |
| #3 | `black` 黑 | x 8.6–358.8，y 10.9–291.7 | 左侧两行大字 |
| 全部 | — | 509.7 × 322.9（长宽比 **1.58**） | 横版字标 |

## 决策

### 只用 path #2（那只方标），不带字

- **字在 36 单位下读不出来**。按官方留白把整支字标塞进 36 画布：图形宽 19 → 高 19 ÷ 1.58 = **12.0 单位**，
  每个字只有 1.5–2 单位高 —— 渲染出来是一道糊。
- **方标本身就是「知乎」这个意思**：`261 × 261` 的正方形，里面是知乎的品牌图形。它在同一套比例下能占满
  19 × 19，是这块素材里唯一在小尺寸下仍然认得出的东西。
- 代价写明白：**少了两行字，识别度靠图形本身**。这是取舍，不是遗漏。

### 几何：图形本体 19 × 19，四周留白 **8.5 / 8.5 / 8.5 / 8.5**

官方配方是「36×36 画布、图形居中、四周留 8–9（图形本体约 18–20）」：

| 样本 | 图形 | 留白 左/右/上/下 |
|---|---|---|
| `agent-team-profile/icon.svg` | 18.0 × 18.0 | 9.03 / 8.93 / 8.57 / 9.39 |
| `voice-input-bundle/icon.svg` | 20.9 × 18.5 | 7.56 / 7.56 / 8.77 / 8.77 |
| **本仓 `icon.svg`** | **19.0 × 19.0** | **8.50 / 8.50 / 8.50 / 8.50** |

做法：`scale = 19 / 261.125 = 0.07276209`，平移量解到「外接框左上角落在 (8.5, 8.5)」，
**把变换烘进坐标**（保留 4 位小数）而不是留一个 `transform` 属性 —— 这样 36 画布里的数字**直接就是**它出现的位置，
下一个人读文件时不用在脑子里做一次矩阵乘法。回读校验：图形外接框 `x 8.500..27.500`、`y 8.500..27.500`，
55 段命令序列与源 path 逐段一致，逆变换回源坐标的最大误差 **0.000678**（四舍五入造成，形状未变）。

### 配色：沿用 logo 自己的 `#0084FF`，**不改色**

「亮暗都要能看」是判据，所以量化过（WCAG 相对亮度，两种主题的卡片底色都取 `--dsw-alias-bg-layer-3`：
亮 `#FFFFFF`、暗 `#2B2B2C`）：

| 候选 | 亮底 | 暗底 | 取小 |
|---|---|---|---|
| **`#0084FF`（logo 原色，本仓采用）** | **3.66** | **3.87** | **3.66** |
| `#1E80FF` | 3.76 | 3.76 | 3.76 |
| `#3B82F6` | 3.68 | 3.85 | 3.68 |
| `#7AAAFF`（官方 icon 用的亮蓝） | 2.33 | 6.08 | 2.33 ✗ |
| `#145AF3`（官方深蓝） | 5.55 | 2.55 | 2.55 ✗ |
| `#2563EB` | 5.17 | 2.74 | 2.74 ✗ |

- `#0084FF` 在两种底色上都过 WCAG 1.4.11「非文本对比」的 **3:1** 下限，且**两边的值几乎对称**（3.66 / 3.87）——
  这正是「亮暗都要能看」想要的性质；官方那两个蓝都是**一边过一边不过**（2.33 / 2.55）。
- 它是**素材自带**的颜色（`assets/logo.svg` 的 path #2 `fill`），不是新调的品牌色 —— 不用维护者再拍一次板。
- **不加底板**（用户明确要求「不是白底」）：图标是透明底 + 单一蓝色图形。
  副作用如实说：**知乎蓝在深色底上偏暗**（3.87 是过线，不是醒目）；要更亮就得上 `#7AAAFF` 那种，
  代价是亮色底掉到 2.33。这一条是取舍，摆在这里备查。

### 去掉投影

源文件那层 `<g filter="...">` 是 `stdDeviation=5` 的白色投影。缩到 36 单位后模糊半径只剩
`5 × 0.0728 = 0.36` 单位、偏移 `0.29/0.15` 单位 —— 在 36 px 的渲染尺寸下不到半个像素，
**只会让边缘发灰**；而且投影是白色的，在亮色主题上本来也看不见。所以**整层 `<g>` 与 `<defs>` 都没要**，
图标只剩一个 `<path>`。

### 自包含

单 path、无 `transform`、无 `filter`、无 `href`/`url(`/`@import`/`<image`/`<style`/`font-family`，
`fill="#0084FF"` 写死不用 `currentColor`（data URL 渲染时它取不到值）。文件 **1567 B**（上限 262144 B）。

## 随包与断言

- `package.json` 顶层 `"icon": "./icon.svg"`，`files` 收录 `icon.svg`。
- **那条「将来声明 icon 时它也要进包」的断言现在真的生效了**：[scripts/plugin-metadata.mjs](../../scripts/plugin-metadata.mjs)
  在原本只判「路径是否越界」的基础上补了四条 —— 文件在、扩展名在宿主名单内、`files` 收录、≤ 256 KiB。
  与展示元数据同一份判定，`npm run check:release` 与 [test/plugin-metadata.test.ts](../../test/plugin-metadata.test.ts) 都读它。
- **防空转（端到端实跑）**：临时把 `"icon.svg"` 从 `files` 里摘掉 → `check:release` **退出码 1**，
  报 `files 收录 icon.svg —— 没随包的图标在 npm 上不存在…`；还原后 `release check passed`（退出码 0）。
  `npm pack --dry-run` 的产物清单里也有 `icon.svg`（1.6 kB）。

## 影响

- **对使用者**：插件页的 bundle 卡片、详情页与设置里的插件清单开始显示这枚图标（此前是面板默认图案）。
  没有它时宿主只留一条诊断、图标位空着 —— 不报错，所以这条链同样由上面的守卫兜住。
- **对截图**：图标**改变卡片外观**，所以重拍卡片图从「更新版本号与文案」升级为**必拍**；
  判废项已写进 [assets/AGENTS.md](../../assets/AGENTS.md) 与 [assets/README.md](../../assets/README.md)。
- **对素材**：`assets/logo.svg` 从「未引用」变成「被 `icon.svg` 派生引用」——
  两者**不是同一份东西**（一个是 523×346 字标、一个是 36×36 图标），
  改 logo 不自动改图标，改图标也不必动 logo。
- **回滚**：删 `icon.svg`、删清单里的 `icon` 与 `files` 那一行。没有别的耦合。
