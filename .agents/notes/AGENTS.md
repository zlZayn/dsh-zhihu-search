# notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

notes/ 特有约束：

- 一条一档，文件名 `YYYY-MM-DD-<主题>.md`。
- **不建索引文件**：目录树 + git 历史就是索引，这里只放记录本身。
- 每条必须写「替代方案」：试过什么、为什么不行。不记被打败的选项，下次必定被重诉。
- **写死当时的事实**，不随代码更新；事实性变化（路径 / 默认值 / 机制名）就地改，决策反转才新写一条并交叉引用。
- 骨架：决策类用 问题 / 决策 / 替代方案 / 影响；备忘类用 事实 / 处置 / 影响。

## 状态标记

第 3 行放一行状态，四值之一。状态行是元数据，不属正文；正文从第一个 `##` 起。

| 状态 | 含义 | 必附 |
| --- | --- | --- |
| `状态：生效` | 当前有效，指导未来工作 | —— |
| `状态：被取代` | 已被后续决策整体或部分取代 | 下一行指针，指向取代它的那条 |
| `状态：已否决` | 提案被否，未实施 | 同行一句话理由 |
| `状态：已归档` | 不再指导未来工作 | 同行日期 + 一句话理由 |

四种写法：

- `状态：生效`
- 第 3 行 `状态：被取代`，第 4 行 `指针：[<标题>](<文件名>.md)`
- `状态：已否决 —— <一句话理由>`
- `状态：已归档（YYYY-MM-DD）—— <一句话理由>`

## 归档规则

- 不再指导未来工作时**就地标记**：状态改 `状态：已归档（YYYY-MM-DD）—— <一句话理由>`。
- **不移动文件、不建 `archived/` 目录**；状态行就是归档的标记。
- 归档后冻结：正文不再更新，只留历史价值。
- 部分被取代不新建文件、不归档：保留原记录，状态改 `状态：被取代`，指针给取代它的那一条。
- 决策反转才新写一条并交叉引用；不改写旧记录的正文。
